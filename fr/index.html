Politique de confidentialité

Dernière mise à jour : 5 octobre 2026.

SetRack ne collecte, ne transmet ni ne partage aucune donnée personnelle. L’app n’a pas l’autorisation internet : ce que tu enregistres (exercices, séries, charges) est stocké uniquement dans la mémoire locale de ton appareil.

Tu gardes le contrôle de tes données :

  • « Sauvegarder » écrit un fichier dans le dossier Téléchargements quand tu le demandes.
  • La sauvegarde Android (si elle est activée sur ton système) peut inclure les données de l’app ; elle se gère dans les paramètres de ton appareil.
  • Désinstaller l’app supprime toutes les données.

Aucune analyse, aucune publicité, aucun traceur ni service tiers. L’app ne déclare pas l’autorisation internet ; sa seule autorisation système est la vibration, utilisée pour le petit retour quand tu notes une série.
